# 📊 EPOCHS Data Science Bootcamp

### 11-Day Data Science Learning Journey

This repository contains my work from the **11-Day EPOCHS Data Science Bootcamp**, where I worked through a series of practical tasks covering **Data Analysis, SQL, Data Visualization, Machine Learning, Clustering, Model Optimization, Deployment, and Generative AI**.

Each task represents a different stage of my learning journey, moving from data exploration and analysis to building and deploying real-world applications.

---

## 🚀 Learning Journey

### 📅 Task 01 — Exploratory Data Analysis

Started with **Exploratory Data Analysis (EDA)** using a hotel booking dataset.

* Dataset understanding
* Data types and missing values
* Statistical analysis
* Data exploration
* Identifying the Machine Learning problem

---

### 📅 Task 02 — SQL & Business Analysis

Worked with the **Northwind database** to answer practical business questions using SQL.

* SQL queries
* Aggregations and analysis
* Sales and customer insights
* Business-oriented data analysis

---

### 📅 Task 03 — Used Car Data Analysis

Performed data cleaning and feature engineering on a **used car dataset**.

* Data preprocessing
* Missing value handling
* Outlier analysis
* Feature engineering
* Relationship between car characteristics and price

---

### 📅 Task 04 — Data Visualization

Explored **Spotify data** and focused on extracting insights through visualization.

* Data exploration
* Distribution analysis
* Correlation analysis
* Visualization
* Data storytelling

---

### 📅 Task 05 — Car Price Prediction

Built Machine Learning models to predict **used car prices**.

* Feature preprocessing
* Regression
* Linear Regression
* Decision Tree
* Random Forest
* Model evaluation

---

### 📅 Task 06 — Customer Churn Prediction

Developed classification models to predict **customer churn**.

* Data preprocessing
* Logistic Regression
* Decision Tree
* Random Forest
* Classification metrics
* Confusion matrix

---

### 📅 Task 07 — Customer Segmentation

Applied **K-Means Clustering** to identify different customer groups.

* Unsupervised Learning
* Feature scaling
* Elbow Method
* K-Means Clustering
* PCA visualization
* Customer profiling

---

### 📅 Task 08 — Model Optimization

Focused on improving Machine Learning models through **hyperparameter tuning**.

* Model comparison
* GridSearchCV
* Hyperparameter tuning
* Model evaluation
* Feature importance

---

### 📅 Task 09 — Machine Learning Deployment

Converted a trained Machine Learning model into an **interactive web application**.

* Model serialization
* Streamlit
* User input handling
* Prediction interface
* Deployment workflow

---

### 📅 Task 10 — AI Study Assistant

Built an **AI-powered Study Assistant** using an LLM-based approach.

* Generative AI
* Prompt Engineering
* API integration
* Frontend & backend communication
* AI-generated explanations
* Web application development

---

### 📅 Task 11 — Folio: AI-Powered PDF Chat

Developed and optimized an **AI-powered PDF chat application** that allows users to interact with documents.

The task also involved researching and experimenting with different deployment platforms and optimizing the application according to hosting constraints.

* PDF processing
* Document-based question answering
* RAG concepts
* Retrieval optimization
* Gradio
* API integration
* Deployment experimentation
* Hosting and memory optimization
* UI/UX improvements

> **AI-Assisted Development:** Cursor Agent was used as an AI-assisted development tool during the optimization, debugging, UI refinement, and deployment stages of Task 11. The development process involved researching different hosting options, testing deployment approaches, identifying platform limitations, and iteratively optimizing the application.
